Высоконадежный модульный Telegram-бот расписания занятий для студентов группы **ИС231** Амурского Государственного Университета (АмГУ).

Бот разработан с упором на максимальную надежность в условиях нестабильного мобильного интернета, защиту сервера вуза от перегрузок и комфортный пользовательский опыт студентов и старосты.

---

## Ключевые возможности

### ⚡ Высокая производительность и отказоустойчивость
- **Многоуровневое кэширование**: оперативная память (`TTL = 30 мин`) + локальная база данных SQLite в режиме `WAL` (время ответа < 0.005 сек).
- **Защита от Cache Stampede**: блокировка `asyncio.Lock` по принципу double-checked locking предотвращает шторм одновременных сетевых запросов к серверу АмГУ.
- **Оффлайн-режим с корректной четностью**: если сервер вуза временно недоступен, бот отдаёт локальную копию, рассчитывая четность недели строго относительно даты создания слепка (`_cached_at_date`).
- **Graceful Shutdown**: корректное освобождение HTTP-пула и закрытие соединений БД при остановке или перезапуске.

### 🔴 Умный статус «Сейчас» (`/now`)
- Показывает текущую пару, аудиторию, преподавателя и визуальный прогресс-бар:
  `[████████░░] 80% • Осталось: 18 мин`
- Информирует о переменной и времени до следующего звонка.
- **Анонс на будущее**: если все пары на сегодня закончились, бот автоматически выводит анонс первой пары на завтра (или на понедельник, если сегодня пятница/выходной).

### 🔔 Расписание звонков и перемен (`/bells`)
- Наглядная сетка времени начала и окончания всех занятий.
- Отображение длительности перемен и обеденного перерыва.

### 🗓 Интерактивный календарь недели (`/week`)
- Инлайн-кнопки по дням недели (`ПН`..`СБ`) с подсветкой выбранного дня.
- Быстрое переключение между текущей и следующей неделями.
- Возможность вывести расписание всей недели одним сообщением.

### 📢 Автоматический детектор изменений расписания (Diff Engine)
- Фоновый чекер (`JobQueue`) каждый час проверяет актуальность расписания через SHA256-хеш.
- При обнаружении любых изменений (перенос аудитории, отмена пары, замена преподавателя) бот мгновенно отправляет дифференциальное уведомление всей группе.

### 🌅🌙 Утренний и вечерний дайджесты
- Утренняя сводка в **07:30** на текущий день.
- Вечерний анонс в **20:00** на следующий день.
- Опция **«Без пар не будить»**: бот не беспокоит студентов в выходные дни и праздники.
- **Безопасная доставка (Safe Broadcast)**: алгоритмический троттлинг (до 25 сообщений/сек) для предотвращения ограничений Telegram Rate Limits (`RetryAfter`) и автоматическое отключение заблокировавших бота пользователей (`Forbidden`).

### 👥 Фильтрация по подгруппам (1-я / 2-я)
- В настройках (`/settings`) студент может выбрать свою подгруппу, скрывая чужие лабораторные и практические занятия.

### 📅 Экспорт в календарь (`.ics`)
- Генерация файла iCalendar RFC 5545 для импорта в **Apple Календарь**, **Google Calendar**, **Яндекс** или **Outlook**.
- Включает точные аудитории, имена преподавателей и автоматические напоминания за 15 минут до пары.

### 💬 Поддержка бесед и групповых чатов
- Бот корректно работает при добавлении в беседу группы: отвечает на команды `/now`, `/today`, `/tomorrow`, `/week`, `/bells`, не навязывая постоянную reply-клавиатуру.

### 🛡 Панель администратора
- `/stats` — сводная статистика: количество пользователей, активность за сутки, подписки на дайджесты и статус API АмГУ.
- `/broadcast <сообщение>` — безопасная массовая рассылка важных объявлений от старосты.

## Архитектура проекта

```
schedule-bot/
├── src/
│   ├── api/             # Асинхронный HTTP-клиент к API АмГУ (httpx, keep-alive)
│   ├── database/        # Слой SQLite (aiosqlite, WAL-режим, транзакции, индексы)
│   ├── handlers/        # Обработчики команд, сообщений и callback-кнопок
│   │   ├── common.py    # /start, /help, /sync, /bells, /stats, /broadcast
│   │   ├── schedule.py  # /now, /today, /tomorrow, /week, кнопки меню
│   │   ├── settings.py  # Меню подгрупп, уведомлений и тихого режима
│   │   ├── calendar.py  # Экспорт .ics
│   │   └── error.py     # Глобальный обработчик ошибок
│   ├── keyboards/       # Разметка клавиатур (Reply & Inline)
│   ├── services/        # Бизнес-логика, JobQueue, Diff Engine, iCal генератор
│   ├── config.py        # Конфигурация, переменные окружения, таймзона (UTC+9)
│   └── bot.py           # Инициализация приложения и жизненный цикл
├── tests/               # Модульные и интеграционные тесты (pytest)
├── .dockerignore        # Исключение секретов и кэша из контейнера
├── Dockerfile           # Non-root образ на базе python:3.11-slim
├── docker-compose.yml   # Декларативный запуск сервиса
├── requirements.txt     # Зависимости проекта
└── bot.py               # Корневая точка входа
```

## Установка и запуск

### Вариант 1: Запуск через Docker Compose (Рекомендуется)

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/ArtemChik103/telegram-schedule-bot.git
   cd telegram-schedule-bot
   ```

2. Создайте файл `.env`:
   ```ini
   TELEGRAM_BOT_TOKEN=ваш_токен_от_BotFather
   ADMIN_ID=ваш_числовой_telegram_id
   ```

3. Запустите контейнер:
   ```bash
   docker compose up -d --build
   ```

4. Просмотр логов:
   ```bash
   docker compose logs -f
   ```

---

### Вариант 2: Локальный запуск

1. Создайте виртуальное окружение и активируйте его:
   ```bash
   python -m venv venv
   # Linux/macOS:
   source venv/bin/activate
   # Windows (PowerShell):
   .\venv\Scripts\Activate.ps1
   ```

2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

3. Настройте файл `.env` (см. пример в `.env.example`).

4. Запустите бота:
   ```bash
   python bot.py
   ```
