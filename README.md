Асинхронный Telegram-бот для доставки расписания занятий студентам группы ИС231 Амурского государственного университета.

Бот кэширует ответы API вуза в памяти и локальной базе данных SQLite, рассчитывает статус занятий и оповещает об изменениях в расписании.

---

## Функциональность

### Кэширование и оффлайн-режим
- Двухуровневое кэширование: оперативная память с TTL 30 минут и локальная база SQLite в режиме WAL.
- Защита от Cache Stampede: блокировка `asyncio.Lock` предотвращает параллельные повторные запросы к серверу вуза.
- Расчет четности в оффлайне: при недоступности API четность недели рассчитывается от даты сохранения локального слепка.
- Корректное завершение работы: приложение закрывает HTTP-клиент и соединения с базой при сигналах остановки.

### Статус текущего занятия (/now)
- Выводит текущую пару, аудиторию, преподавателя и текстовый индикатор выполнения.
- Выводит время до окончания перемены.
- Выводит анонс первой пары на следующий учебный день после завершения всех пар текущего дня.

### Звонки и перемены (/bells)
- Выводит расписание звонков с указанием длительности каждой перемены и обеденного перерыва.

### Календарь на неделю (/week)
- Инлайн-кнопки по дням недели (ПН-СБ).
- Переключение между текущей и следующей неделями.
- Вывод полного расписания на неделю одним сообщением.

### Мониторинг изменений расписания
- Фоновая задача проверяет контрольную сумму расписания (SHA256) каждый час.
- При обнаружении переносов, отмен или смены аудиторий бот рассылает уведомления подписчикам.

### Утренние и вечерние дайджесты
- Утренняя рассылка в 07:30.
- Вечерняя рассылка в 20:00.
- Режим тишины: опция отключения утренних сообщений в дни без занятий.
- Безопасная отправка: ограничение скорости до 25 сообщений в секунду для соблюдения лимитов Telegram API.
- Автоматическая деактивация рассылок для пользователей, заблокировавших бота.

### Выбор подгруппы
- Фильтрация расписания по подгруппам (1-я или 2-я) в меню настроек (`/settings`).

### Экспорт в календарь (.ics)
- Генерация файла iCalendar по стандарту RFC 5545 для Google Calendar, Apple Calendar и Outlook.
- Включает локацию, преподавателя и напоминание за 15 минут до начала занятия.

### Работа в групповых чатах
- Обработка команд `/now`, `/today`, `/tomorrow`, `/week` и `/bells` в беседах без отправки постоянной нижней клавиатуры.

### Команды администратора
- `/stats`: статистика по числу пользователей, активным подпискам и статусу API.
- `/broadcast <текст>`: пакетная рассылка сообщений по активной базе пользователей.

## Структура проекта

```
schedule-bot/
├── src/
│   ├── api/             # HTTP-клиент к открытому API АмГУ
│   ├── database/        # Слой данных SQLite (aiosqlite)
│   ├── handlers/        # Обработчики команд и callback-запросов
│   ├── keyboards/       # Разметка клавиатур
│   ├── services/        # Расчет расписания, генерация .ics, рассылки
│   ├── config.py        # Переменные окружения и настройки
│   └── bot.py           # Конфигурация Application
├── tests/               # Модульные и интеграционные тесты
├── .dockerignore        # Исключения для сборки контейнера
├── Dockerfile           # Образ на базе python:3.11-slim с непривилегированным пользователем
├── docker-compose.yml   # Конфигурация запуска Docker
├── requirements.txt     # Зависимости Python
└── bot.py               # Точка входа
```

## Установка и запуск

### Способ 1: Запуск через Docker Compose

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/ArtemChik103/telegram-schedule-bot.git
   cd telegram-schedule-bot
   ```

2. Создайте файл `.env`:
   ```ini
   TELEGRAM_BOT_TOKEN=ваш_токен
   ADMIN_ID=ваш_telegram_id
   ```

3. Запустите контейнер:
   ```bash
   docker compose up -d --build
   ```

4. Просмотрите логи:
   ```bash
   docker compose logs -f
   ```

---

### Способ 2: Локальный запуск

1. Создайте и активируйте виртуальное окружение:
   ```bash
   python -m venv venv
   source venv/bin/activate  # Linux/macOS
   .\venv\Scripts\Activate.ps1  # Windows PowerShell
   ```

2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

3. Настройте файл `.env` на основе `.env.example`.

4. Запустите приложение:
   ```bash
   python bot.py
   ```
